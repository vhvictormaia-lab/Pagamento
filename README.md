# Cartão de Ponto

Site para registrar o ponto todo dia e calcular o salário do mês.

- 4 horários por dia: entrada, saída do almoço, volta do almoço e saída
- Dias de segunda a sexta já vêm com o horário padrão (8:00–11:30 / 12:30–18:00, sexta até 17:00); é só corrigir o que for diferente
- Horas extras separadas por tipo, com dias, horas, valor da hora com o adicional e total:
  - Dia útil: 50%
  - Sábado: 60%
  - Domingo: 100%
  - Feriado: 100% (marque o dia no botão F)
- Demonstrativo no formato de holerite: proventos, INSS, IRRF e líquido
- INSS calculado só sobre o salário base (tabela 2026)
- IRRF com a isenção até R$ 5.000 e o redutor até R$ 7.350 de 2026

## Como usar

Abra o site pelo GitHub Pages ou o `index.html` no navegador. Os registros ficam salvos no próprio navegador.
Em **Configurações e backup**, use "Baixar backup" de vez em quando para guardar uma cópia das horas, e "Carregar backup" para recuperar em outro aparelho.
