# Cartão de Ponto

Site para registrar o ponto todo dia e calcular o salário do mês.

- 4 horários por dia: entrada, saída do almoço, volta do almoço e saída
- Dias de segunda a sexta já vêm com o horário padrão (8:00–11:30 / 12:30–18:00, sexta até 17:00)
- Hora extra em dia útil (50%), sábado (60%) e feriado/domingo (100%)
- INSS calculado só sobre o salário base (tabela 2026)
- IRRF com a isenção até R$ 5.000 de 2026

Para usar, abra o `index.html` no navegador. Os registros ficam salvos no próprio navegador.
